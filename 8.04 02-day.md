## 一、任意类型和类型推导

## 一、任意类型和类型推导

`dynamic` 类型可以存储任意类型的值，并且可以随时修改成其他类型的值。

语法：dynamic 变量名 = 值;

示例：

dynamic a = 10;
Console.WriteLine($"a: {a}");        // 输出：a: 10
a = "hello";
Console.WriteLine($"a: {a}");        // 输出：a: hello
a = true;
Console.WriteLine($"a: {a}");        // 输出：a: True

| 方法/特性     | 含义             | 示例                                         | 说明                                                 |
| :------------ | :--------------- | :------------------------------------------- | :--------------------------------------------------- |
| **dynamic**   | 不限制变量类型   | `dynamic a = 10;` `a = "hello";` `a = true;` | 可以赋任意类型的值，且可以修改成其他类型的值         |
| **var**       | 自动捕获变量类型 | `var n = 10;` `// n = 10.1; // 报错`         | 根据赋值的数据类型确定变量类型，不可以修改为其他类型 |
| **GetType()** | 检测变量类型     | `Console.WriteLine(a.GetType());`            | 返回变量的实际数据类型                               |

## 二、匿名类型

匿名类型也叫匿名对象，类似集合，将多个数据集中在一个变量中，由键值对组成，方便访问其中的每个数据。

语法：var 变量 = new { 键名 = 键值, ..... };

示例：

var user1 = new
{
    name = "leon",
    age = 18,
    gender = 1
};
Console.WriteLine(user1.name);  // 输出：leon
// user1.name = "lemon"; // 不可以修改
// user1.Add("info", 1); // 不可以添加

| 方法/特性    | 含义                 | 示例                                          | 说明                         |
| :----------- | :------------------- | :-------------------------------------------- | :--------------------------- |
| **new { }**  | 创建匿名类型         | `var user = new { name = "leon", age = 18 };` | 将多个键值对集中在一个变量中 |
| **键名访问** | 通过键名访问对应的值 | `Console.WriteLine(user1.name);`              | 只能获取值，不能修改和添加   |

## 三、数据字典（Dictionary）

数据字典是一种以**键值对**形式存储数据的集合，可以新增和修改数据。

语法：

Dictionary<键的类型, 值的类型> 变量名 = new Dictionary<键的类型, 值的类型>()
{
    ["键名1"] = 值1,
    ["键名2"] = 值2,
};

示例：

Dictionary<string, dynamic> user = new Dictionary<string, dynamic>()
{
    ["name"] = "谢谊",
    ["age"] = 18,
    ["gender"] = "boy",
    ["girlFriend"] = new Dictionary<string, dynamic>()
    {
        ["name"] = "覃东稳",
        ["age"] = 24,
        ["gender"] = "girl",
    }
};

| 方法名称        | 含义                   | 示例                                                         | 说明                                          |
| :-------------- | :--------------------- | :----------------------------------------------------------- | :-------------------------------------------- |
| **索引器 [ ]**  | 通过键名访问/修改/添加 | `Console.WriteLine(user["name"]);` `user["girlFriend"]["name"] = "翠花";` `user["height"] = 180;` | 键存在则访问/修改，键不存在则添加             |
| **Count**       | 获取元素个数           | `Console.WriteLine(user.Count);`                             | 获取字典中键值对的总数量                      |
| **Remove**      | 删除指定键             | `user.Remove("gender");`                                     | 删除指定键名的键值对                          |
| **Clear**       | 清空所有数据           | `user.Clear();`                                              | 清空字典中所有键值对                          |
| **TryGetValue** | 尝试获取值             | `user.TryGetValue("name", out dynamic val)`                  | 安全获取值，返回 bool，避免访问不存在的键报错 |

## 四、数组（Array）

数组是一个**固定长度**的容器，用来存放多个**数据类型相同**的元素。数组中多个数据按顺序存储，每个小空间以下标（从0开始）操作。

语法：

// 语法1：指定长度
类型[] 变量名 = new 类型[长度];

// 语法2：直接赋值，自动推断长度
类型[] 变量名 = [值, ....];

// 语法3：老版本使用 {}
类型[] 变量名 = {值, ....};

示例：

string[] stu = ["张三", "李四", "王五"];
int[] arr1 = [10, 20, 30];

// 访问
Console.WriteLine(arr1[0]);  // 输出：10

// 修改
arr1[0] = 100;
Console.WriteLine(arr1[0]);  // 输出：100

// 获取长度
Console.WriteLine(arr1.Length);  // 输出：3

// 不能新增
// arr1[3] = 123; // 报错，超出范围

| 方法/属性      | 含义                  | 示例                                           | 说明                    |
| :------------- | :-------------------- | :--------------------------------------------- | :---------------------- |
| **索引器 [ ]** | 通过下标访问/修改元素 | `Console.WriteLine(arr1[0]);` `arr1[0] = 100;` | 索引范围：0 到 Length-1 |
| **Length**     | 获取数组长度          | `Console.WriteLine(arr1.Length);`              | 返回数组中元素的总个数  |

## 五、List 集合

List 是**加强版的数组**，可以动态新增和删除元素。

语法：

List<数据类型> 变量名 = new List<数据类型>()
{
    值1,
    值2,
    ...
};

示例：

List<string> stus = new List<string>()
{
    "张三",
    "李四",
    "王五",
    "赵六",
};
Console.WriteLine(stus[0]);  // 输出：张三
Console.WriteLine(stus.Count);  // 输出：4

| 方法名称        | 含义                  | 示例                                                | 说明                                        |
| :-------------- | :-------------------- | :-------------------------------------------------- | :------------------------------------------ |
| **索引器 [ ]**  | 通过下标访问/修改元素 | `Console.WriteLine(stus[0]);` `stus[0] = "田七";`   | 索引范围：0 到 Count-1                      |
| **Count**       | 获取元素个数          | `Console.WriteLine(stus.Count);`                    | 获取 List 中元素的总数量                    |
| **Add**         | 末尾新增一个数据      | `arr1.Add(100);`                                    | 在小括号中放新增的数据                      |
| **AddRange**    | 末尾新增多个数据      | `arr2.AddRange(new List<string>() { "FF", "GG" });` | 参数必须是集合                              |
| **Insert**      | 任意下标新增数据      | `arr3.Insert(2, "f");`                              | 新增数据的下标范围 0 到 Count               |
| **Remove**      | 删除指定数据          | `nums.Remove(20);`                                  | 删除第一个匹配的元素                        |
| **RemoveAt**    | 删除指定下标数据      | `nums1.RemoveAt(2);`                                | 删除指定索引位置的元素                      |
| **RemoveRange** | 删除指定范围多个数据  | `nums2.RemoveRange(1, 2);`                          | 从下标开始删除指定个数                      |
| **Clear**       | 清空所有数据          | `nums3.Clear();`                                    | 清空后 Count = 0                            |
| **Contains**    | 判断是否包含某个数据  | `sArr2.Contains("b")`                               | 返回值为布尔值                              |
| **IndexOf**     | 查找首次出现的下标    | `sArr3.IndexOf("c")`                                | 找到返回下标，找不到返回 -1                 |
| **LastIndexOf** | 查找最后出现的下标    | `sArr4.LastIndexOf("b")`                            | 找到返回下标，找不到返回 -1                 |
| **GetRange**    | 获取多个数据          | `sArr5.GetRange(2, 3)`                              | GetRange(开始下标, 个数) 返回一个 list 集合 |
| **Reverse**     | 翻转                  | `sArr6.Reverse();`                                  | 将列表顺序倒过来                            |

## 六、随机数（Random）

语法：

Random r = new Random();
int num = r.Next(9);          // 获取 0-9 的随机整数，不包含 9
double num1 = r.NextDouble(); // 获取 0-1 的随机浮点数

示例：

// 使用 List 存放多个姓名
List<string> students = new List<string>()
{
    "谢谊","覃东稳","姜添舒","张小松","方锦",
    "黄陆基","王耀腾","李佳鑫","蓝启耿","周佳龙",
    "黄宇盛","韦炳湘","韩旭颖","钟朝林","曾杰文",
    "李卓达","彭钇霖","田健","何战胜","徐诚",
    "张仁杰","龙昊","陈佳","陈志锋","王明宇",
    "李之阳","潘家涵","蓝浩天","杨天硕","董俊涛",
    "蒙琛","张英玉","陈煜松","莫远宁","李家良",
    "丁佳俊","谭森华","刘宏阳","宁东明","崔世锦","唐海波",
};

// 随机生成下标
Random r = new Random();
int i = r.Next(students.Count);
Console.WriteLine(students[i]);

| 方法名称         | 含义           | 示例             | 说明                          |
| :--------------- | :------------- | :--------------- | :---------------------------- |
| **Next(n)**      | 获取随机整数   | `r.Next(9)`      | 获取 0~9 的随机整数，不包含 9 |
| **Next(n, m)**   | 获取随机整数   | `r.Next(1, 5)`   | 获取 1~5 的随机整数，不包含 5 |
| **NextDouble()** | 获取随机浮点数 | `r.NextDouble()` | 获取 0~1 之间的随机浮点数     |

## 七、数据结构

### 1、商品数据结构

单个商品使用**字典**存储比较合适，多个商品使用 **List 集合**存储。

数据结构：

商品（字典）
├── img: 图片
├── name: 名称
├── price: 价格
└── introduce: 描述

示例：

List<Dictionary<string, dynamic>> goods = new List<Dictionary<string, dynamic>>()
{
    new Dictionary<string, dynamic>()
    {
        ["name"] = "耳机",
        ["img"] = "图片地址",
        ["price"] = 110,
        ["introduce"] = "描述1",
    },
    new Dictionary<string, dynamic>()
    {
        ["name"] = "儿童桌",
        ["img"] = "图片地址",
        ["price"] = 1200,
        ["introduce"] = "描述2",
    },
    new Dictionary<string, dynamic>()
    {
        ["name"] = "鼠标",
        ["img"] = "图片地址",
        ["price"] = 24,
        ["introduce"] = "描述4",
    }
};

### 2、歌曲数据结构

单个歌曲使用**字典**存储，评论使用 **List 集合**存储，单个评论也使用**字典**存储。

数据结构：

歌曲（字典）
├── name: 歌名
├── author: 作者
├── lrc: 歌词
└── comment: 评论列表（List）
    └── 评论（字典）
        ├── name: 评论者
        └── content: 评论内容

示例：

List<Dictionary<string, dynamic>> songs = new List<Dictionary<string, dynamic>>()
{
    new Dictionary<string, dynamic>()
    {
        ["name"] = "鲨鱼宝宝",
        ["author"] = "谢谊",
        ["lrc"] = "歌词1",
        ["comment"] = new List<Dictionary<string, dynamic>>()
        {
            new Dictionary<string, dynamic>()
            {
                ["name"] = "覃东稳",
                ["content"] = "下个歌王"
            },
            new Dictionary<string, dynamic>()
            {
                ["name"] = "张学友",
                ["content"] = "下一个歌神"
            }
        }
    },
    new Dictionary<string, dynamic>()
    {
        ["name"] = "下一个天亮",
        ["author"] = "姜添舒",
        ["lrc"] = "歌词1",
        ["comment"] = new List<Dictionary<string, dynamic>>()
        {
            new Dictionary<string, dynamic>()
            {
                ["name"] = "周杰伦",
                ["content"] = "下次别唱"
            },
            new Dictionary<string, dynamic>()
            {
                ["name"] = "张小松",
                ["content"] = "一起唱...."
            }
        }
    },
};
